หน้านี้อธิบายว่า Sudo Command เก็บและใช้ข้อมูลอย่างไร ทั้งจากเว็บไซต์นี้ และจากเครื่องมือ GoldVideo Poster ที่เราใช้โพสต์คลิปวิดีโอลงเพจ Facebook ที่เราดูแลให้ลูกค้า

This page explains how Sudo Command collects and uses data on this website and in GoldVideo Poster, the tool we use to publish videos to Facebook Pages we manage for our clients.

1. GoldVideo Poster ทำอะไร

GoldVideo Poster เป็นเครื่องมือภายในของ Sudo Command ใช้โพสต์คลิปวิดีโอที่เราผลิตลงเพจ Facebook ของลูกค้า ตามตารางเวลา และเฉพาะเพจที่เจ้าของเพจอนุญาตให้เราดูแลแล้วเท่านั้น ไม่ได้เปิดให้บุคคลทั่วไปล็อกอินหรือใช้งาน

GoldVideo Poster is an internal tool. It publishes videos we produce to Facebook Pages whose owners have authorized us to manage them, on a schedule. It is not offered to the public and has no public login.

2. ข้อมูลที่เข้าถึง

  • รหัสเพจ ชื่อเพจ และโทเค็นการเข้าถึงเพจ (Page access token) ที่เจ้าของเพจมอบให้ ใช้เพื่อโพสต์คลิปเท่านั้น
  • ข้อมูลของโพสต์ที่เราโพสต์เอง เช่น รหัสโพสต์ เวลาโพสต์ และสถานะการเผยแพร่ ใช้ตรวจว่าโพสต์ขึ้นสำเร็จ

เราไม่เก็บข้อมูลส่วนบุคคลของผู้ใช้ Facebook ที่เข้ามาดูเพจ เช่น ชื่อ รายชื่อเพื่อน ข้อความ หรือข้อมูลการติดต่อ

Data accessed: Page ID, Page name and the Page access token granted by the Page owner (used only to publish), plus IDs, timestamps and publishing status of posts we create. We do not collect personal data of Facebook users who view the Page.

3. การเก็บรักษาและการแบ่งปัน

โทเค็นและบันทึกการโพสต์เก็บไว้ในเครื่องที่ Sudo Command ควบคุมเท่านั้น ไม่ขาย ไม่ให้เช่า และไม่ส่งต่อให้บุคคลภายนอก และไม่ใช้เพื่อโฆษณาหรือวิเคราะห์ผู้ใช้ เราเก็บโทเค็นไว้จนกว่าเจ้าของเพจจะยกเลิกสิทธิ์หรือสิ้นสุดการใช้บริการ

Tokens and posting logs are stored only on systems controlled by Sudo Command. We never sell, rent or share them with third parties, and never use them for advertising or user profiling. Tokens are kept until the Page owner revokes access or the service ends.

4. เว็บไซต์นี้

ถ้าคุณติดต่อเราผ่านฟอร์มหรืออีเมลบนเว็บไซต์ เราใช้ชื่อ ช่องทางติดต่อ และรายละเอียดงานที่คุณส่งมา เพื่อตอบกลับและเสนองานเท่านั้น

If you contact us through this website, we use the name, contact details and project details you send only to reply and prepare a proposal.

เว็บไซต์นี้เก็บเฉพาะภาษาที่เลือกและธีมหน้าจอใน localStorage ของเบราว์เซอร์ (sc-lang และ sc-theme) ลบได้จากการตั้งค่าข้อมูลเว็บไซต์ ข้อความที่เตรียมในช่องรายละเอียดงานอยู่ในหน่วยความจำของหน้านี้ ไม่ได้ส่งเข้าเซิร์ฟเวอร์หรือบันทึกลง localStorage อัตโนมัติ ปุ่มร่างอีเมลเปิดแอปอีเมลให้คุณตรวจและส่งเอง ส่วนปุ่มคัดลอกนำข้อความไปไว้ในคลิปบอร์ดของอุปกรณ์

Language and theme preferences (sc-lang and sc-theme) are stored in browser localStorage and can be cleared in your browser settings. Brief drafts stay in page memory; they are not automatically uploaded or stored in localStorage. Draft email opens your email app for review and sending. Copy places the text on your device clipboard.

หน้าเว็บโหลดแบบอักษรจาก Google Fonts และให้บริการผ่าน GitHub Pages ผู้ให้บริการเหล่านี้ได้รับข้อมูลการเชื่อมต่อ เช่น IP และข้อมูลเบราว์เซอร์ ตามการให้บริการของตน การเปิด LINE, Messenger, Facebook หรือเว็บไซต์ผลงานจะพาคุณไปยังผู้ให้บริการนั้น เราไม่ได้ติดตั้งเครื่องมือติดตามโฆษณาหรือวิเคราะห์ผู้เข้าชมในหน้าเว็บรุ่นนี้

Fonts load from Google Fonts and hosting is provided by GitHub Pages. These providers receive connection information such as IP address and browser details. LINE, Messenger, Facebook and project links take you to those providers. This version of the website has no advertising trackers or visitor analytics installed.
