# Sudo / Signal design direction

## Critique of the previous composition
- Oversized decorative wordmark and concentric circles displaced the actual project.
- Hard shadows, clipped corners, rotated frames and boxed service cards competed without a shared hierarchy.
- Tiny captions and excessive mixed monospace weakened Thai readability.
- Homepage and destination pages looked unrelated; modal actions competed with the screenshot.

## References inspected
- https://www.instrument.com/ : direct work-led hierarchy, consistent navigation and spacious project presentation.
- https://www.rejouice.com/ : deliberate scale, editorial whitespace and consistent typography.
- https://www.facebook.com/reel/2205555447024803 : user reference describes procedural WebGL motion.
- https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Tutorial/Adding_2D_content_to_a_WebGL_context : API reference.
No third-party artwork, logo, project claims or client results copied.

## Direction
Original green Sudo logo preserved. Orange remains the action accent. Warm neutral surfaces, restrained dark stages, consistent radii and readable Thai typography. The opening project now owns the full media width. Three real thumbnail selectors replace the decorative wordmark column. A custom WebGL signal field sits behind it as progressive enhancement, with CSS fallback, low-resolution rendering, visibility suspension, reduced motion and a pause control.

Restyled header/menu, hero, all work cards, motion archive, recommendation selector, service accordions, packages, about, process, FAQ, contact form, footer, mobile dock, image modal, command palette and static detail/portfolio destinations. No paid dependency or hosting change. Existing behavior and real content preserved.

Production build is required. No automated tests were requested. Visual authoring views are not a full browser/device audit or a claim to outperform reference websites.
