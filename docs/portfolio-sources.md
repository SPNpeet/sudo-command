# Public portfolio publication boundary

Owner instruction: show conceptual business flow only for operational apps, back offices and automation. Do not expose system entry points, trial access, source repositories, internal manuals, configuration, workflow exports or implementation screens.

The public portfolio uses three purpose-drawn conceptual flow illustrations in place of previous operational screenshots. They are clearly labelled as conceptual, not actual system screens. Public project outbound destinations have been removed. Published promotional reels remain examples of final output.

Detailed research notes and removed pictures are retained locally outside this repository for the owner. Earlier public Git commits and third-party caches may still contain previously published material. This change removes it from the current release; it does not claim retrospective erasure or change permissions on separate project repositories.
