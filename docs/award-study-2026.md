## Critique of previous Sudo version
- Repeated rounded rectangular panels flattened hierarchy across unrelated sections.
- A full-width browser screenshot had scale, but little project context.
- Similar-size portfolio cards made the work read as a catalogue.
- Project popup sidebar had spare space while its contextual caption sat below the image.

## Applied design
- Spatial project theatre: three real project screens with layered perspective,
  selected project narrative, manual previous/next and accessible category controls.
- Stronger Thai headline and quieter supporting copy.
- Alternating 7/5 and 5/7 editorial project columns, with controlled vertical offsets.
- Numbered process line instead of four interchangeable cards.
- Larger indexed menu links and more intentional hover/focus responses.
- Popup context in the sidebar on desktop; original caption retained on mobile.
- Original green logo and orange/white identity preserved.
- Native page scrolling, no entry gate or automatic audio. Motion has pause and
  reduced-motion support. Functional content does not depend on WebGL.

Build: npm run build completed. No automated tests were added or run.
Browser views were used during visual authoring; no exhaustive device or performance audit claimed.
